# Painel Financeiro Pessoal

Painel HTML autônomo (sem build, sem dependências de servidor) para controle das despesas
pessoais do CEO — fechamento mensal, cartão de crédito PF, importação de fatura (.xlsx) e
histórico salvo automaticamente no navegador.

## Como usar

Baixe `painel-financeiro-pessoal.html` e abra direto no Chrome. Os dados ficam salvos
localmente no navegador; use os botões de exportar/importar JSON para backup ou para levar
os dados para outro computador.
